# CLAUDE.md — Project Instructions

## Component Naming

Before writing, editing, or reviewing any content in `docs/product/analytics/`, validate all component names and abbreviations against the project glossary at `docs/product/analytics/08-glossary.md`.

Do not use component names or abbreviations from memory. If a name has changed (e.g. SIL → SVL, NSE → NSA, IRE → IRA), the glossary is the authoritative source. When a user refers to a component by an old or informal name, silently resolve it to the current glossary name before proceeding.

If a proposed rename or new component is discussed, update the glossary as part of the same change — never let the glossary fall behind the documents.
